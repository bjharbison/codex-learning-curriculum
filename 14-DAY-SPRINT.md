# Fourteen-Day practice-focused Sprint

**Commitment:** 90–120 minutes/day. Daily cadence: 20 minutes concept, 60–75 minutes hands-on, 20 minutes documentation and teach-back. A tested artifact matters more than rushing.

| Day | Focus | Proof |
| --- | --- | --- |
| 1 | Role and tools | Competency matrix, repo map |
| 2 | GitHub safety | Reviewed practice change |
| 3 | Threat modeling | One-page threat model |
| 4 | Secure code review | Evidence-backed findings |
| 5 | Vulnerability triage | Ranked findings |
| 6 | Patch verification | Remediation pull request |
| 7 | Detection engineering | Detection hypothesis and false-positive notes |
| 8 | Incident response | Response timeline and decision log |
| 9 | Daybreak workflow | Access checklist and honest comparison |
