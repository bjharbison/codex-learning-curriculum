# Week 1 — Foundations and safe setup

**Target:** 5 days at 30–60 min/day. For the faster schedule use [the accelerated track](../ACCELERATED-TRACK.md). Track completion in [PROGRESS.md](../PROGRESS.md).

## Day 1

### Understand ChatGPT, Codex, and the development workflow

**Objective:** Compare ChatGPT planning, Codex implementation, GitHub review, and Claude Code; draw your workflow.

**Exercise:** Explain when each tool should be used.

**Do this:**
1. Ask ChatGPT for a plain-language explanation of the concept and one example based on a repository you own.
2. Ask Codex to inspect and explain the relevant code or workflow. For investigation, insist on no edits.
3. Create a feature branch where edits are required; implement the smallest solution.
4. Check the diff and run available validation. Document tests you could not perform.
5. Record a commit/PR and notes in the [learning journal](../LEARNING-JOURNAL.md), then check this lesson in [PROGRESS.md](../PROGRESS.md).

**Definition of done:** Explain when each tool should be used.

**Mentor prompt:**
> I'm on Day 1 of a Codex beginner-to-proficient curriculum. Teach me understand chatgpt, codex, and the development workflow while helping me complete this task: Explain when each tool should be used. First explain your plan; do not merge or deploy without approval, and explain test evidence and any remaining uncertainties.
