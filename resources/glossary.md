# Glossary

**Codex:** software-development coding agent. **Daybreak Blue:** approval-based access for authorized defensive cybersecurity work. **Diff:** exact file changes. **PR:** review proposal before merge. **Regression test:** checks that a resolved problem does not recur. **Threat model:** assets, trust boundaries, threats and controls. **CVSS:** vulnerability severity scoring framework. **EPSS:** estimate of exploitation likelihood, not proof of exploitation. **CIS Controls IG1:** prioritized essential cyber hygiene controls. **NIST CSF:** framework to manage cybersecurity risk. **RMF:** risk-management and authorization process. **Authorizing Official:** designated accountable risk acceptance authority. **Detection engineering:** constructing evidence-based monitoring logic. **Enablement:** helping others sustainably adopt tools and practices. **Train-the-trainer:** preparing instructors to scale learning. **Human–AI teaming:** deliberate assignment of AI assistance and accountable human review.
