# Beginner glossary

**Repository:** tracked project files and history. **Branch:** isolated development line. **Commit:** recorded snapshot. **Diff:** comparison of changed code. **Pull request:** reviewable proposal to merge changes. **Merge:** combine approved branches. **Revert:** undo a prior change. **CLI:** terminal commands. **Build:** prepare executable/deployable code. **Unit test:** checks one small unit. **Integration test:** checks components together. **Smoke test:** rapid check of key functionality. **Regression test:** ensures a fixed problem stays fixed. **API:** communication interface between software systems. **Dependency:** external library. **CI:** automated checks for changes. **Threat model:** structured description of assets, trust boundaries and security risks. **Vulnerability triage:** verify and prioritize candidate issues. **Daybreak Blue:** approved tier supporting authorized defensive cyber workflows on supported models. **AGENTS.md:** repository-local instructions for compatible agents.
