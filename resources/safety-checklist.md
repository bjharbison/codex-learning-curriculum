# Agent and Cybersecurity Safety Checklist

- [ ] Correct repository and isolated feature branch
- [ ] Assessment scope explicitly owned or authorized
- [ ] No secrets, personal identifiers, government/work/customer data in prompts
- [ ] Read-only investigation and small plan before edits
- [ ] Review every diff, external action, package and command
- [ ] Tests/build/manual verification completed (or gaps documented)
- [ ] No unapproved merge, deployment or external assessment
- [ ] Human approval and rollback documented
- [ ] Public portfolio contains no sensitive vulnerability disclosures
- [ ] Daybreak Blue used only after approval and only as provisioned
